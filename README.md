# Abyss Lab · 深渊实验室

一只异星生命的 Canvas 2D 生态箱原型。当前开发边界是 **P0 工程基础 + P1 生命感与交互**：生物自主探索、觅食、进食和休息，玩家通过投喂、引导与安抚获得即时行为反馈。

## 本地运行

需要 Node.js 22.12+，推荐 Node.js 24。

```sh
npm ci
npm run dev
```

在浏览器中打开 Vite 输出的地址。页面不依赖外部图片、字体或服务；生物、环境与粒子由 Canvas 几何绘制。开发服务器绑定 `0.0.0.0`，可在网络允许时通过同一局域网内设备访问。

## 验证命令

```sh
npm run typecheck
npm test
npm run build
npm run test:browser
```

浏览器测试需要可用的 Playwright Chromium；具体环境要求与执行证据见 [验收记录](docs/acceptance.md)。`npm run preview` 可预览 `dist/` 中的生产构建。

需要不启动服务器的本地审查文件时，在正常构建后执行：

```sh
npm run build
node scripts/export-preview.mjs
```

生成的 `dist/abyss-lab-preview.html` 内嵌脚本与样式，可在浏览器允许本地文件访问时直接打开，也可通过 `npm run preview` 访问。它沿用同一模拟与界面，没有增加存档或离线推进能力。本轮云端浏览器的管理员策略禁止 `file://`，不能把该环境中的本地文件打开报告为通过。

## 项目结构

```text
src/
  simulation/  世界类型、种子随机与固定步行为逻辑；不依赖 React
  runtime/     真实时间累积、固定步调度及实测倍率
  rendering/   Canvas 几何、状态动画与环境
  components/  界面组件
  App.tsx      React 界面与模拟/绘制的连接
tests/         模拟、调度及浏览器验证
docs/          本轮决策与验收边界
```

同一种子、相同初始世界和相同步号上的命令序列，产生相同模拟结果。渲染帧率不直接决定生物状态；视图可对相邻模拟快照插值。网页暂停或进入后台时不计算离线进度。

## 操作与观察

- **投喂**：选择投喂后点击或触摸生态箱，在指定位置放置食物。观察生物转向、接近、摄食以及核心发光变化。
- **引导**：在生态箱内指定关注点，观察有持续时间的好奇与接近反应。
- **安抚**：在生物附近使用安抚；有效范围、冷却和接收反馈限制连续点击。
- **被动供食**：维持自动生成的基础营养。主动投喂与照护另有行为及信任反馈。
- **暂停、倍率与救援**：检查不同推进速度；休眠时启动救援，不需要剩余健康或能量。

生态箱边缘的投喂与引导会映射到内侧可达区域，保留完整生物形态；安抚仍按真实点击位置判断距离。具体机制、恢复条件、倍率定义和范围取舍见 [P0–P1 决策记录](docs/decisions-p0-p1.md)。

## 当前边界

这是单生物、单会话原型。当前不含存档、离线收益、成长升级、遗传繁殖、多生物生态或后端服务。刷新页面会回到初始状态。P2–P5 不在本轮实现范围内。

云端测试通过只能证明明确的技术断言。生命感、视觉品质、真实移动设备手感和试玩乐趣仍需用户验收，不能由截图或自动化测试替代。

本轮已实际执行类型检查、40 个单元测试、生产构建及 2 个浏览器集成场景。云端曾出现实际倍率低于目标的长帧，异常提示已验证；持续 4× 性能与真实移动设备性能尚未验收。日志、截图和执行边界见 [验收记录](docs/acceptance.md)。

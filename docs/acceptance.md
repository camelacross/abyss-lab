## 浏览器验证与真实倍率证据

桌面场景验证了实际 Canvas 像素、键盘近身投喂、接近摄食、营养变化、有效安抚及冷却反馈、鼠标光引与移动、右键不触发交互、暂停冻结、暂停点击不会假报请求成功、恢复推进，以及基础供食开关。移动仿真验证了实际 `touch` 指针、坐标映射、投喂摄食和页面无横向溢出。

最终测试在浏览器内以约 10 Hz 采集 40 个样本，记录真实墙钟、已发布步号、显示倍率、状态和丢弃时间。末端窗口显示 **3.87×**，独立 DOM 步号/墙钟粗估 **4.25×**，差值 0.38× 在 5 Hz 界面更新造成的两端量化容差 0.75× 内。该粗估是交叉检查，不能解释为模拟实际超出 4×；固定步精度由运行器单元测试验证。该窗口有丢弃时间，界面正确显示「推进延迟」。[原始采样](evidence/speed-samples.json) 也包含在结果 JSON 的 `actual-speed-samples` 附件中。

随后实际阻塞主线程 400 毫秒，累计丢弃模拟时间从 **3.28 秒增加到 4.15 秒**，实测 **3.57×**，并出现「推进延迟」。这验证了异常反馈，没有把裁剪后的时间冒充完整墙钟时间。

调试期间的首次浏览器运行被并行格式化触发的 Vite 热更新中断；第二次暴露了测试直接点击被装饰层覆盖的原生 checkbox，改为点击真实可用的 label；另一次要求持续 4× 的断言因云端实际长帧失败，观察到约 0.97–2.52× 并正确告警。该次性能失败保留在 [过载执行记录](evidence/browser-overload-run.log)。最终功能测试验证的是推进、测量与异常反馈的正确性，**没有宣称持续 4× 性能通过**。

## 云端验证范围

| 需求 | 可自动验证的断言 |
| --- | --- |
| 确定性与隔离 | 相同初始种子和命令序列得到相同结果；输入状态不被改变；核心不依赖 React |
| 自主行为 | 无玩家输入时会移动和改变行为；目标、速度、位置和数值始终有效 |
| 食物与反馈 | 生成、接近、摄食产生相应结果；主动与被动食物有不同收益；冷却与数量上限有效 |
| 休眠救援 | 健康与能量同时为零，救援条件可用时能恢复；不可用时不会假报成功；重复命令不会阻塞恢复 |
| 固定步推进 | 不同帧率、分帧方案和 1×/2×/4× 下，已执行步数符合累计时间 |
| 时间异常 | 长帧裁剪和丢弃时间可见；实测倍率按完整活跃墙钟计算；暂停恢复不追赶隐藏时间 |
| 浏览器集成 | 页面可打开、Canvas 有实际内容、操作可改变状态、无运行时错误；条件允许时检查响应式布局 |

截图展示的是某一时刻的真实界面，只能支持布局与画面检查；连续动画和行为变化还需现场观察。模拟单元测试不能替代 Canvas、事件坐标转换和 React 生命周期的集成验证。

## 用户验收清单（尚未验收）

- [ ] 正常倍率观察至少 2 分钟：能辨认鳐形躯体、膜翼、六条分节触须与发光核心，形态完整，没有被裁掉或像平面图标。
- [ ] 观察探索、转向、觅食、进食、休息：节奏、翼幅、触须和发光变化与当前行为相符。
- [ ] 在不同位置投喂：生物会调整路径并实际靠近，摄食瞬间的视觉与状态结果一致。
- [ ] 对比被动供食和主动照护：主动行为有清楚且有意义的差异，连续点击不是唯一有效策略。
- [ ] 近距离与远距离安抚、引导：接收或拒绝信息清晰，反馈能被察觉。
- [ ] 观察休眠救援完整过程：危机与恢复可理解，健康、能量归零不会造成无法退出的循环。
- [ ] 在实际手机或平板上操作：纵横屏、点击和触摸坐标准确，控件可触达，页面滚动与生态箱交互不冲突。
- [ ] 在实际设备连续运行至少 10 分钟：画面流畅度、发热、耗电与可读性可接受。
- [ ] 完成至少 10 分钟试玩后判断：生命是否有自主性、是否会对环境和玩家作出可信反应、主动照护是否值得继续。

## 当前交付限制

- 单生物、单会话原型，刷新后回到初始状态；不包含存档和离线进度。
- 页面隐藏或显式暂停时，模拟与自动救援停止推进；恢复可见后继续。
- 状态数值、行为节奏和主动照护收益属于 P1 原型参数，尚未经过用户长期试玩平衡。
- 真机性能、触摸手感和视觉生命感不能仅凭云端环境确认。
- 云端实际出现慢帧和模拟时间丢弃；持续 4×、长时间流畅度及真实移动设备性能尚未验收。截图中的「推进延迟」属于真实测量反馈。
- P2–P5 未实施，也不构成本轮未完成缺陷。
